# 🪄 The Wizarding Portfolio — Shekha Abdullah Almamari

A stunning, responsive, single-page **Harry Potter / Hogwarts-themed** portfolio for
**Shekha Abdullah Almamari** — *Network & Database Specialist · Tech Innovator*.

Built with **HTML5**, **Tailwind CSS** (via CDN), and **Vanilla JavaScript** — no build step required.

## ✨ Magical Features

- **Hero Section** — glowing ancient-gold title with a starry-night particle sky and floating, flickering candles.
- **Custom Wand Cursor** — a glowing wand-tip that leaves a trail of golden sparks (JS particle system).
- **Marauder's Map Reveal** — sections fade-in and "ink-spread" into focus as you scroll.
- **Lumos Spell Buttons** — buttons that glow and shimmer on hover.
- **3D Tilt Cards** — achievement & project cards tilt toward the cursor.
- **Spell Cards** — flippable skill cards revealing each magical talent.
- Fully **responsive** and **mobile-friendly**, with graceful fallbacks for touch devices and
  `prefers-reduced-motion`.

## 📜 Sections

1. **Magical Achievements** — awards & honours.
2. **Leadership & Academic Experience** — a golden timeline.
3. **The Spellbook of Projects** — innovative tech projects.
4. **Magical Talents** — interactive flip spell cards.

## 🚀 Run it

No installation needed. Just open the file:

```bash
# Option 1: open directly
open index.html        # macOS
xdg-open index.html    # Linux

# Option 2: serve locally (recommended)
python3 -m http.server 8000
# then visit http://localhost:8000
```

## 🗂️ Structure

Everything lives in a **single self-contained file** — just download `index.html`
and double-click it to open in any browser.

```
index.html   — markup, styles & scripts all in one file
```

> Note: Tailwind and the Google Fonts load from a CDN, so an internet connection
> is needed the first time you open it.
